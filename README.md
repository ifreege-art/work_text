# イラスト発注書ジェネレーター

自分用のイラスト発注書作成ツール。Netlify(静的ページ + Functions + Blobs)で動作します。

## デプロイ
1. このリポジトリをNetlifyに接続(ビルドコマンドなし、公開ディレクトリは `public`)
2. 環境変数 `APP_PASSWORD` を設定(ログイン用パスワード)。任意で `SESSION_SECRET`(セッション署名用)
3. デプロイ後、サイトを開いてログイン

## 使い方
1. 「マスタ」で自分の情報・相手(制作者)・規約・既定値を登録
2. 「発注書」から新規作成 → 保存 → 発行
3. 発行後に表示される同意用URLを相手に送る(相手は氏名入力と同意ボタンで同意)
4. 印刷・PDFで書類を出力(同意済みなら同意記録付き)
5. 発行済みの発注書から「請求書を作成」(全額・割合・金額指定の分割請求、追加明細に対応。インボイス登録番号はマスタでオンオフ)

画面幅900px以下(スマホ)は閲覧専用です。

## 開発
- `npm test` … 金額計算のテスト
- `node test/api.test.mjs` … APIのテスト(Blobsはダミー)
- `node test/serve.mjs` … ローカル確認用サーバー(http://localhost:8890、パスワード `pw`)
